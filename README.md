# Street City Web

Protótipo 3D de mundo aberto executado diretamente no navegador.

## Controles
- WASD: movimentar
- Shift: correr
- Espaço: pular
- Mouse: câmera
- E: entrar/sair do carro

## Publicação
O projeto é estático e pode ser publicado gratuitamente com GitHub Pages. Use a raiz do branch `main` como fonte do Pages.
